# Sudoku

## [Play](https://rhnh.github.io/sudoku)

## Keybindings

| Keys                 | function                |
| -------------------- | ----------------------- |
| n or + sign          | toggle notes            |
| u                    | Undo the last move      |
| Backspace/Delete/0   | Delete a number         |
| 1-9                  | Number 1 to 9           |
| space                | Start the game          |
| ra                   | Restart                 |
| z                    | Zen Mode                |
| i                    | Show info               |
| Arrows Keys and WASD | Move around the board   |
| Ctrl+Click           | Select multiple squares |
| Ctrl+s               | show FEN Input          |
